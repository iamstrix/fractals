# SEJIAN // Generative Shader Apparel & Fractal Engine

A real-time WebGL mathematical fractal synthesizer and luxury darkwear/streetwear apparel generation pipeline.

---

## 📁 Repository Structure

```text
├── index.html              # Main interactive WebGL fractal explorer, audio reactivity, and lab
├── shirt_mockup.html       # WebGL interactive t-shirt shader projection mockup player
├── brainstorming.html      # Brand blueprint, market strategy, and apparel lookbook
├── operators.html          # GLSL space folding & fractal operator visualizer
│
├── assets/
│   ├── mockups/            # 3D apparel mockups, production specs, and lookbook renders
│   │   ├── nano_banana_3d_shirt_mockup_1788084776242.jpg   # 1:1 Box print mockup
│   │   ├── flesh_shirt_all_over_mockup.jpg                 # Full AOP shirt mockup
│   │   ├── flesh_shirt_front_back_side_mockup.jpg          # 3-view production spec (Front/Back/Side)
│   │   ├── flesh_shirt_typographic_quote_mockup.jpg        # Brutalist masked quote tee
│   │   ├── mockup_neoclassical_fractal_tee.jpg             # Neoclassical disruption graphic tee
│   │   ├── mockup_y2k_paneled_fractal_tee.jpg              # Y2K cut-and-sew paneled tee
│   │   └── y2k_shirt_editorial_lookbook.jpg                # Cyber-darkwear editorial campaign shot
│   └── logos/              # SEJIAN brand identity, wordmarks, and monograms
│
├── notes/                  # Research, algorithm notes, and shader presets
│   ├── a.txt               # Raw GLSL raymarching / palette shader snippet
│   ├── b.txt               # Preset shader database (FLESH, GLITCHGEOM, VOIDDRIVE, etc.)
│   └── txt.txt             # Project notes & name-to-fractal configuration pipeline
│
└── audits/                 # Code audits and feature comparison reports
```

---

## 🚀 Key Web Entry Points

- **`index.html`**: Open in any modern browser to explore real-time fractals, tweak mathematical constants, randomized seeds, and audio reactivity.
- **`brainstorming.html`**: Comprehensive brand blueprint detailing design archetypes, product roadmap, and physical apparel mockups.
- **`shirt_mockup.html`**: Live vector t-shirt canvas overlaying real-time WebGL shader feeds.
